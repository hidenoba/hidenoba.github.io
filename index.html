PERSONAL FILE ORGANIZER

Google Driveの文書を、
PC内のAIで整理する。

AI File Organizerは、指定した一時保存フォルダの文書を読み取り、登録済みの保存先との関連を判断するWindows用の個人向けアプリです。

配布条件：購入者限定
本アプリは、Brainで販売する「AIはフォルダから始まる」の購入者限定で配布します。

指定フォルダを監視

利用者が設定したINBOX内の文書を定期的に確認します。移動先は事前に登録した既存フォルダに限ります。

曖昧な判断は保留

PC内AIによる2回の判定が一致し、所定の条件を満たした文書だけ移動します。判断が曖昧な文書はINBOXに残します。

移動先を確認

専用のGoogleスプレッドシートに、処理状態・移動先・判断理由を表示します。操作履歴をPCにも記録します。

Googleとの接続について

利用者自身のGoogle認証により、Driveからのファイル取得と移動、専用スプレッドシートの更新を行います。本文のAI処理は利用者のPC内で行い、この運用では外部のAIサービスへ自動で切り替えません。

Googleの認証画面では、Drive全体の読み取り・メタデータ管理、Googleスプレッドシートの操作など、アプリ内の操作対象より広い権限が表示されます。実際の操作対象はアプリの設定と検証で制限しています。詳細はプライバシーポリシーをご覧ください。

自動削除・ゴミ箱への移動・同名ファイルへの上書きは行いません。AIの分類には誤りがあり得るため、重要な文書はバックアップと結果の確認をお願いします。

動作する環境

Windows PC、PC内で動くOllamaのモデル、インターネット接続が必要です。PCの電源が入り、監視プログラムが動いている間に処理します。スリープ中・電源オフ中は処理しません。このWebページ自体にログインやファイル送信の機能はありません。
