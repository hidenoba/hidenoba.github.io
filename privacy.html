プライバシーポリシー

更新日：2026年10月7日

このポリシーは、AI File OrganizerのPC内AIによるGoogle Drive整理と、専用スプレッドシートへの結果表示に適用します。外部AIを明示的に設定して使う別の運用は、このページで説明する構成には含みません。

取得する情報と利用目的

情報利用目的
ファイル・フォルダの情報ファイルID、名前、種類、サイズ、日時、親フォルダ、バージョン、所有者・共有状態・操作可否を取得し、対象範囲と安全な移動条件を確認します。
対象文書の内容INBOX内の対応形式の文書を取得し、本文を抽出して、PC内AIで保存先を判断します。内容のハッシュ値を計算し、処理中の変更と移動結果を検証します。
Googleの認証情報アクセス用・更新用トークン等を利用し、利用者が許可したGoogle APIへの接続を維持します。Googleのパスワードはアプリで受け取りません。
分類結果と処理履歴移動候補、判断理由、確信度、処理日時、元と移動先の情報、操作結果を記録し、確認・重複処理防止・復旧・Undoに利用します。

Googleへのアクセス範囲

移動用の認証ではDriveの読み取り（drive.readonly）とメタデータ管理（drive.metadata）を要求します。一覧更新用の認証ではDriveの読み取りとGoogleスプレッドシート操作（spreadsheets）を要求します。これらのOAuth権限自体はINBOXや一覧1個に限定されません。

アプリは指定INBOXと登録した移動先を操作対象とし、所有者・共有状態・配置などを検証します。一覧の更新は、明示的に登録した専用スプレッドシートの管理範囲に限定します。原本の自動削除やゴミ箱への移動は行いません。

処理場所・外部への送信

文書のAI分類は利用者のPC内のOllamaで実行します。この構成では文書本文を外部AIサービスへ送信せず、学習用データとして収集しません。アプリはGoogle DriveとGoogle Sheetsへ必要なAPI要求を送信します。

専用の移動先一覧には、ファイル名・リンク・処理状態・移動先・判断理由・処理日時・確信度を送信します。判断理由には文書内容への言及や抜粋が含まれる場合があります。運用者の別サーバーへの文書収集、広告利用、販売は行いません。

Google APIから受け取った情報は、このページに記載したファイル整理・結果確認・復旧のために使用し、Google API Services User Data PolicyのLimited Use要件を含む規定に従って取り扱います。

保存と保持期間

認証ファイルは利用者のPCの専用保存先に保存します。取得した文書は処理のための一時ファイルとして扱い、通常は処理後に除去します。処理中断時などに一時ファイルが残る場合があります。

ファイル情報・ハッシュ値・分類結果・操作履歴はPC上のSQLiteとログに保存し、自動で期限を決めて削除しません。プロジェクトや履歴の保存先がOneDriveなどの同期対象の場合、その同期サービスの設定に従ってクラウドにも保存されます。利用者が設定したバックアップにも記録が残る場合があります。

Google Drive上の原本はGoogle Driveに保存されます。一覧は最新1000ファイルを表示し、過去の操作記録はPCの履歴に残ります。

停止・許可の取り消し・データの削除

利用者は監視プログラムを停止し、Googleアカウントの接続管理からアプリのアクセス許可を取り消せます。許可を取り消しても、PCの履歴やDriveの原本・一覧は自動では削除されません。

認証ファイル、履歴、ログ、一時ファイル、一覧、バックアップの削除は、監視を止めて必要なデータを確認したうえで利用者が行えます。履歴を削除するとUndoや未確定操作の復旧ができなくなることがあります。削除方法やデータの取り扱いは下記へお問い合わせください。
